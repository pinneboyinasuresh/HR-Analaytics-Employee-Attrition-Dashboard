# HR Analytics & Employee Attrition Dashboard

## Project Overview
This project analyzes employee data to understand attrition patterns and explore the factors associated with employees leaving an organization. An interactive Power BI dashboard was developed to present key workforce insights.

## Tools & Technologies
- **Python**
- **Pandas**
- **Power BI**
- **DAX**

## Dataset
The project uses the IBM HR Analytics Employee Attrition & Performance dataset, containing 1,470 employee records and 35 original columns.

## Project Workflow
1. **Data Cleaning:** Inspected the dataset and removed unnecessary constant columns using Python and Pandas.
2. **Exploratory Data Analysis:** Analyzed attrition by department, job role, age group, overtime, job satisfaction, years at company, and monthly income.
3. **Dashboard Development:** Built an interactive Power BI dashboard with KPI cards, charts, and slicers.
4. **DAX Measures:** Created measures to calculate total employees, employees who left, and attrition rate.

## Key Insights
- **Total Employees:** 1,470
- **Employees Who Left:** 237
- **Overall Attrition Rate:** 16.12%
- Explored attrition patterns across employee demographics, job roles, departments, overtime, satisfaction, and income.

## Dashboard Features
- KPI cards for workforce metrics
- Department, gender, and overtime slicers
- Interactive charts for exploring attrition patterns
- DAX-based attrition rate calculation
